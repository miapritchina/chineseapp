Proposed <Entity> Variants

One component, four sizes. Same visual stack everywhere: pinyin (top) → hanzi (center) → meaning + POS inline (bottom). Status ★ in top-right corner at medium+.

Mapping M → P

Which proposed variant replaces each existing card type.

Current (M) Name → Proposed (P) Notes
M1 Shelf Card P3 Medium. Primary use case.
M2 Result Row M2 (keep) Keep current horizontal row layout. Hanzi left, pinyin+gloss right, star far-right.
M3 EntitySheet Header P4 Large, with component breakdown. Owner likes M4's role-color fills (not just border) — consider for component glyphs inside P4.
M4 Etymology Glyph M4 (keep) Keep current role-colored text glyphs in decomposition equation. Don't unify — the colored-text approach is better than bordered cards here.
M5 "In Your Saved Words" → M2 Merge with Result Row layout. Same horizontal row style as M2.
M6 NodeCard (tree) Custom Needs its own redesign. Keep role-colored border + etymology note. Not a standard P variant — unique to the tree modal context.
M7 Bank Chip P2 Small Entity. Compact card for word bank grid.
M8 Composer Token P1 Tiny Entity. Minimal inline token in sentence composer.
M9 Phonetics Row Custom (M6+M2) Hybrid: row layout like M2, richness like M6's tree card. + sound 🔊 button. Family preview strip stays.
M10 Component Chip P1 Tiny, pill variant.
M11 Review Hanzi P5 (mod) Hero, but with white background and even bigger hanzi than current P5.
M12 Drill Pick Button P1 Tiny, with correct/wrong border state.
M13 Cluster Cell P2 Small Entity, with hidden/revealed state overlay.
M14 Disambig Cell P2 Small Entity, side-by-side layout. Downsized from P5 Hero.
M15 Graph Node P1 Tiny. Role-colored circle/shape.
M16 Saved Sentence Row Custom (M9+M5+M2) Hybrid: M2's row layout, M5's "saved words" context, M9's phonetics features. A rich sentence row combining all three patterns.

Usage example: "M7 (Bank Chip) should use P3 (Entity Medium) with a POS-color left border" — or — "M4 should stay as P2 but with the role-color coming from the parent decomposition context."
